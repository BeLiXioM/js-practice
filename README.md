# JavaScript Practice

Упражнения для закрепления JavaScript.

## Темы

- Функции, параметры и аргументы.
- Возвращаемые значения.
- Области видимости функции и блока.
- Использование результата одной функции в другой.
- Вложенные функции и замыкания: сохранение доступа к переменным, независимые счётчики.
- Методы объектов и this.
- Потеря контекста при отдельном вызове метода и привязка через bind.
- Стрелочные функции и сохранение this из окружающей области.
- Создание независимых объектов через функцию-фабрику.

## Запуск

Требуется Node.js.

Запуск упражнений: `node functions.js`.
Упражнения на замыкания: `node closures.js`.
Упражнения на this: `node this.js`.
